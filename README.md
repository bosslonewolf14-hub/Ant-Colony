# Ant Colony — เกม Clicker/Idle รังมด 3D (Three.js)

เกมเล่นบนเว็บเบราว์เซอร์ (คอมและมือถือ ทั้งแนวตั้งและแนวนอน) สร้างด้วย Three.js + Vite ไม่มี Server ข้อมูลเซฟเก็บใน `localStorage` ของเบราว์เซอร์

## วิธีเล่นสั้น ๆ
- แตะผลเบอร์รี่บนสนามหญ้าเพื่อเก็บอาหาร ซื้อมดงานให้หาอาหารเอง (อาหารเข้าตอนมดเดินมาส่งที่ห้องราชินี)
- ฟักไข่สุ่มมด 5 ระดับ (Common → Legendary) มี Luck และ Pity มดแต่ละ Rank เก็บอาหารได้ไม่เท่ากัน
- คลังอาหารมีความจุจำกัด ขยายได้สูงสุด 8 ห้อง (ห้องใหม่โผล่ลึกลงไปใต้ดิน ลาก/เลื่อนเพื่อดู)
- ศัตรูบุกเป็นคลื่น ซื้อมดนักรบ/ค่ายนักรบเพื่อป้องกัน
- ห้องวิจัย สกิลราชินี ผลเบอร์รี่ทอง สภาพอากาศ ภารกิจ และก่อตั้งอาณานิคมใหม่ (Royal Jelly โบนัสถาวร)

## รันตอนพัฒนา
```bash
npm install
npm run dev
```
เปิด http://localhost:5173

## Build เป็นไฟล์ static
```bash
npm run build
```
ได้โฟลเดอร์ `dist/` นำทั้งโฟลเดอร์ไปวางบนเว็บโฮสต์แบบ static ที่ไหนก็ได้ (XAMPP: คัดลอกไปไว้ใน `htdocs` แล้วเปิด `/ชื่อโฟลเดอร์/`, หรือ GitHub Pages / Netlify / Cloudflare Pages) ตั้งค่า `base: './'` ไว้แล้ว จึงเปิดจากโฟลเดอร์ย่อยได้ ถ้าจะเปิดไฟล์ตรง ๆ แบบ `file://` เบราว์เซอร์บางตัวบล็อกโมดูล ให้เปิดผ่านเว็บเซิร์ฟเวอร์เสมอ ทดลองดูก่อนด้วย `npm run preview`

ต้องเปิดผ่าน HTTPS (หรือ localhost) หากต้องการให้เสียงและโหมดเต็มจอทำงานครบบนมือถือ

## ปรับบาลานซ์ (ไม่ต้องแก้โค้ด)
ตัวเลขทั้งหมดอยู่ใน `src/config/`

| ไฟล์ | เนื้อหา |
|---|---|
| `economy.json` | ราคา/สูตรอัปเกรด รายได้มดงาน ความจุคลัง ไข่ ออฟไลน์ เซฟ |
| `ants.json` | ตารางมด 5 ระดับ น้ำหนักสุ่ม อัตราเก็บอาหาร Pity |
| `raid.json` | ศัตรู เลือด/ความแรง ความยากต่อคลื่น รางวัล/บทลงโทษ |
| `research.json` | ต้นไม้งานวิจัย 9 หัวข้อ |
| `events.json` | ผลเบอร์รี่ทอง สภาพอากาศ สกิลราชินี |
| `prestige.json` | สูตร Royal Jelly และสิ่งที่คงไว้ตอนก่อตั้งใหม่ |
| `missions.json` | ภารกิจทั้งหมดและรางวัล |

หมายเหตุ: ใน dev server ถ้าแก้ไฟล์ JSON ที่หลายโมดูลใช้ร่วมกัน ควรรีสตาร์ท `npm run dev` เพื่อให้ค่าตรงกันทุกส่วน

## โครงสร้าง
```
src/
  core/    ตรรกะเกม (ไม่แตะกราฟิก): economy, raid, events, research, prestige, missions, save, rng
  scene/   ฉาก 3D: world, rooms, ants, raid, golden, weather, cameraRig
  ui/      HUD, แผงร้านค้า, แท็บต่าง ๆ
  config/  ตัวเลขบาลานซ์ (JSON)
  dev/     เครื่องมือจำลองบาลานซ์ (ใช้เฉพาะตอน dev ไม่ถูกรวมใน build)
```

ตอนรัน `npm run dev` เปิด Console แล้วเรียก `__fullSim({ minutes: 90 })` เพื่อจำลองการเล่นเต็มระบบ (ดูตัวเลือกใน `src/dev/fullSim.js`)

## ข้อจำกัด
- เกมเล่นคนเดียวและไม่มี Server ผู้เล่นแก้เซฟในเครื่องตัวเองได้ ถ้าจะทำอันดับ/ระบบออนไลน์ต้องเพิ่มฝั่ง Server
- เวลาที่ใช้คำนวณรายได้ตอนปิดเกมอ้างอิงนาฬิกาเครื่องผู้เล่น
- การบุกและเหตุการณ์สุ่มไม่เกิดตอนปิดหน้าเว็บ
